**MineDash** — современная веб-панель управления ботами Minecraft на базе `Mineflayer`. Проект является глубоким реворком (форком) панели **BlockMineJS**, в котором полностью переработан пользовательский интерфейс в стиле **Google Pixel — Material Design 3 (Material You)**, улучшена стабильность, безопасность и расширены возможности автоматизации.

Репозиторий проекта BlockMineJS находится **[тут](https://github.com/blockmineJS/blockmine)**.

---

## Что нового в реворке MineDash

### 1. Полный редизайн в стиле Google Pixel (Material Design 3 / Material You)
* **Фирменная типографика Google** — интерфейс использует шрифты **Google Sans / Outfit / Plus Jakarta Sans / Roboto** для заголовков и элементов управления, а для консоли бота и редактора кода сохранён чёткий консольный моноширинный стек **JetBrains Mono / Roboto Mono** с поддержкой лигатур.
* **Тональные поверхности и геометрия Material You (Android 14/15 Pixel)** — глубокие серо-синие и тонированные поверхности (`Surface`, `Surface Container`), скруглённые карточки (`rounded-3xl`), модальные окна (`28px`), капсульные кнопки (`rounded-full`) и переключатели `Switch` с динамическим размером бегунка.
* **Боковая панель Navigation Drawer / Rail и плитки быстрых действий** — навигация с тональными пилюлями активного раздела и плитки на дашборде в стиле шторки быстрых настроек Google Pixel (`Quick Settings Tiles`).
* **Пресеты тем Material You** — встроенные цветовые палитры (`Pixel Синий`, `Pixel Мята`, `Pixel Лаванда`, `Pixel Персик`, `Pixel Светлый`, `Полночь`, `Изумруд`, `Закат`, `Роза`, `Норд`, `Дракула`, `Бумага`, `Небо`), а также полноценный визуальный редактор собственной темы.

### 2. Безопасность и изоляция данных
* **Изолированное хранилище** — база данных SQLite и конфигурация хранятся отдельно, не конфликтуя с другими установками.
* **Безопасность по умолчанию** — панель по умолчанию слушает только `127.0.0.1:3001`, телеметрия отключена, встроен фильтр утечки секретов и токенов в логах.

## Быстрый старт

### Требования
* **Node.js 22 LTS** или новее
* **Windows**, **Linux** или **macOS**

### Запуск на Windows
Дважды нажмите на файл **`start.bat`** в корне папки. Скрипт автоматически проверит версию Node.js, при первом запуске установит зависимости, применит миграции базы данных и откроет панель в браузере по адресу `http://localhost:5173/`.

### Запуск через терминал (Linux / macOS / Windows)
```bash
git clone https://github.com/ssweezyxxx/MineDash.git
cd MineDash
npm install
npm run dev
```

При первом входе в браузере (`http://localhost:5173`) панель предложит создать учётную запись администратора.
